# Touch Game Support

Contact [guchinale@gmail.com](mailto:guchinale@gmail.com) for help with Touch Game.

## Playing

Select one to four winners, then tap Start Game. Each player places one finger on the screen. Keep fingers down for the three-second countdown. There must be more fingers than winners, with a maximum of five fingers.

Selected fingers display Winner. The game resets automatically after three seconds. Tap Settings to change the number of winners.

## If a round does not start

Use more fingers than the selected winner count. Keep fingers in the game area and away from Settings and system gestures. Lifting or adding a finger restarts the countdown. If the device or accessibility settings intercept multi-touch gestures, try another device or adjust those settings yourself.

## Privacy

Touch Game works offline and does not collect personal data. Read the [privacy policy](privacy.html) for details.
